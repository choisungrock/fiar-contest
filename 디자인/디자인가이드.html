K-라이스페스타 품평회 UI 디자인 가이드

전문가 품평회 시스템의 일관성 있는 화면 개발을 위한 디자인 토큰 및 컴포넌트 표준 명세입니다.

1. Color System

앱 전반에 걸쳐 사용되는 핵심 브랜드 색상 목록입니다.

#1b2a4a
Secondary Dark

#b58a2e

#f3e2b8
Accent Red
#e03b3b
Accent Green
#3ea06a
Body Background
#eef1f6
Form Background
#f4f6fa

2. Typography

기본 폰트는 Pretendard를 권장하며 아래의 계층을 따릅니다.
Main Title
대회 메인 타이틀 (32px, ExtraBold)
Section Title
섹션 및 메뉴 타이틀 (22px, Bold)
Table Code
A-1 / 가-1 분류코드 (16px, ExtraBold)
Body Bold
본문 강조 텍스트 (15px, Bold)
Body Regular
본문 기본 설명 텍스트 (14px, Regular)

3. Button Components

핵심 인터랙션을 담당하는 버튼 종류입니다.
<!-- 액션형 버튼 (빨강) -->
<button class="btn-primary">+ 새 대그룹 만들기</button>

<!-- 시작/진행형 버튼 (남색) -->
<button class="btn-secondary">평가 시작하기 →</button>

<!-- 보조/수정 버튼 (아웃라인) -->
<button class="btn-outline">← 수정하기</button>

4. Tab & Status Buttons

부문 선택 및 진행 상태에 따른 탭 디자인입니다.
A 조리
B 비조리
가 저도주 ✓
<!-- 활성 탭 -->
<div class="btn-tab-active"><span>A</span> <span>조리</span></div>

<!-- 비활성 탭 -->
<div class="btn-tab-inactive"><span>B</span> <span>비조리</span></div>

<!-- 완료된 탭 -->
<div class="btn-tab-completed"><span>가</span> <span>저도주</span> <span>✓</span></div>

5. Table Input Cells

평가자 테이블 내부에서 점수 입력 여부를 표현하는 셀 버튼 규격입니다.
입력 대기
입력 완료
<!-- 점수 입력 전 -->
<button class="cell-btn-empty">입력</button>

<!-- 점수 입력 후 -->
<button class="cell-btn-filled">12</button>

6. Form Controls

이름 입력 등 사용자 입력을 받는 텍스트박스입니다.
<div class="form-group">
  <label class="form-label">평가자 (심사위원 성명)</label>
  <input type="text" class="form-input" placeholder="예) 홍길동 심사위원">
</div>
