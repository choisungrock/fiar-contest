품평회 시스템 - 관리자 UI 디자인 가이드

대그룹 설정, 데이터 등록 및 결과 집계 분석을 담당하는 관리자 웹앱 전용 컴포넌트 표준 규격입니다.

1. Color System

관리자 콘솔에서 핵심 레이아웃 구성 및 집계 매트릭스 강조용으로 사용되는 브랜드 컬러 정보입니다.
Primary Dark (헤더/사이드바)
#1b2a4a
Secondary Dark (서브헤더)
#243a63
Accent Red (활성 메뉴/저장)
#e03b3b
Accent Gold (진행률 바)
#b58a2e
Matrix Max (최고점 강조)
#eef4fb / #2f5488
Matrix Min (최저점 제외)
#fbebeb / #c0392b
Matrix Final (최종합계 열)
#fbf4e2 / #8a6a1e
Matrix Total (단순합계 열)
#f1f7f1 / #2f5a3a

7. Result Matrix & Rank Calculation Table

심사위원별 평가 결과를 한눈에 비교하고, 최고/최저 점수를 제외한 최종 순위를 계산하는 집계 그리드입니다.

<!-- 최고/최저 및 합계 강조 표시 클래스 가이드 -->
<td class="matrix-td"><span class="score-min">98</span></td> <!-- 제외된 최저점 -->
